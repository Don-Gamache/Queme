Once your runs are created, it's time to add the dogs that will be competing. Queme gives you two ways to do this: **manual entry** for adding dogs one at a time, and **Excel import** for loading an entire class list in a single step. Both methods result in the same outcome — dogs appear in the run with their names visible to participants immediately, and each dog starts with a default status of "Not Yet Checked In."

## Add a Dog Manually

Manual entry is the quickest option when you have a short list or need to add a single dog on the fly during your event.

<Steps>
  <Step title="Open the Run">
    From your Host dashboard, navigate to the event and tap the run you want to add a dog to.
  </Step>
  <Step title="Tap Add Dog">
    Tap the **Add Dog** button inside the run to open the dog entry form.
  </Step>
  <Step title="Enter the Dog's Details">
    At minimum, enter the **dog's name**. You can also add the **handler's name** to help participants and staff identify the correct team. Fill in any additional fields that appear.
  </Step>
  <Step title="Save the Dog">
    Tap **Save**. The dog is added to the run immediately and is visible to anyone following the event or run.
  </Step>
</Steps>

## Import Dogs from Excel

For larger classes, manually entering every dog is time-consuming. The Excel import lets you prepare your dog list in a spreadsheet and upload the whole class at once.

<Steps>
  <Step title="Prepare Your Spreadsheet">
    Open a spreadsheet application (Microsoft Excel, Google Sheets, or similar) and create a list of dog names — and handler names if desired — with each dog on its own row. Save the file in Excel format (`.xlsx`).
  </Step>
  <Step title="Open the Run in Queme">
    Navigate to the event and tap the run you want to import dogs into.
  </Step>
  <Step title="Tap the Import Option">
    Look for the **Import** or **Import from Excel** option within the run. Tap it to open the file picker.
  </Step>
  <Step title="Select Your File">
    Choose the `.xlsx` file you prepared. Queme reads the spreadsheet and maps the entries to dog records within the run.
  </Step>
  <Step title="Confirm the Import">
    Review the preview of imported dogs and confirm. All dogs from the spreadsheet are added to the run in order.
  </Step>
</Steps>

<Tip>
  Use the Excel import for any class with more than a handful of dogs — it saves significant time and reduces the chance of data entry errors. Prepare your spreadsheet before the event day so you can import the full list the moment you're ready.
</Tip>

## Default Status and Run Order

Every dog added to a run — whether manually or via import — starts with a status of **Not Yet Checked In**. This status is visible to participants so they know which dogs have not yet arrived or been verified at the event.

Dogs appear in the run in the order they were added or imported. You can reorder dogs within a run at any time by using the drag handles in the run's dog list. Reordering updates the live run order that participants see in real time.

<Note>
  Participants can see the dog list as soon as you add dogs to a run. They can immediately tap the bell icon next to their dog's name to start following it and receive push notifications for status updates.
</Note>
