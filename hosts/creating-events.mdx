Creating an event in Queme is the first step toward giving participants a live, connected experience at your dog show, trial, or competition. Events can run for **up to 7 days**, making them suitable for everything from a single-day fun run to a multi-day championship. Once your event is published, participants can find it in the app, follow it, and start receiving live updates the moment you begin managing run orders and dog statuses.

## Create Your Event

<Steps>
  <Step title="Open the Queme App">
    Launch Queme and make sure you're in **Host View**. If you see the Participant interface, tap the Switch View option to switch to your Host dashboard.
  </Step>
  <Step title="Tap the Create Event Button">
    From your Host dashboard, tap the **+** button or the **Create Event** option to open the new event form.
  </Step>
  <Step title="Enter Your Event Details">
    Fill in the required fields:
    - **Event Name** — choose a clear, searchable name that participants will recognize (e.g., "Spring Classic Agility Trial 2025")
    - **Start Date** — the first day of your event
    - **End Date** — the last day of your event (must be within 7 days of the start date)
  </Step>
  <Step title="Save the Event">
    Tap **Save** or **Create**. Your event is now live in the Queme app and visible in the event listing so participants can find and follow it.
  </Step>
</Steps>

<Tip>
  Choose an event name that participants can easily search for. Including the event type, location, or year (e.g., "Lakeside NADAC Trial – June 2025") makes your event much easier to discover in the app.
</Tip>

## Event Duration

<Note>
  Events in Queme can span a **maximum of 7 days**. If your competition or series runs longer than 7 days, consider creating separate events for each week or segment.
</Note>

## Event Credits

Each event you create consumes **one host credit**. New host accounts come with 2 free credits, so you can create up to 2 events right away. The credit is used when the event is created, so make sure your event name and dates are correct before saving.

If you run out of credits or have billing questions, reach out to the support team at [support@queme.io](mailto:support@queme.io) or call **314-295-3893**.
