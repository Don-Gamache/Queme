In Queme, a **run** is a distinct time slot, ring, or class within your event — the building block that organizes dogs into competing groups. You might have a run for each ring at an agility trial, each height division at a conformation show, or each time block at a fun match. Queme lets you add **unlimited runs** to any event, so your structure can be as simple or as detailed as your competition requires.

## Add a Run to Your Event

<Steps>
  <Step title="Open Your Event">
    From your Host dashboard, tap the event you want to manage to open the event detail screen.
  </Step>
  <Step title="Tap Add Run">
    Tap the **Add Run** button to open the run creation form.
  </Step>
  <Step title="Name Your Run">
    Enter a descriptive name for the run. Be specific — participants use the run name to identify where their dog is competing (e.g., "Ring 1 – 8" Standard Agility" or "Masters JWW – Saturday AM").
  </Step>
  <Step title="Choose a Run Style">
    Select one of the two available run styles:
    - **Time-Slot Style** — organizes the run around scheduled time blocks, ideal for events with set start times per class.
    - **Whiteboard Style** — a flexible order list, like a running queue, where dogs are sequenced without fixed time slots. Great for informal trials or when the order is determined on the day.
  </Step>
  <Step title="Save the Run">
    Tap **Save**. The run is immediately added to your event and visible to participants who are following the event.
  </Step>
</Steps>

<Tip>
  Use descriptive run names that include the ring number, class type, and height or level when applicable — for example, "Ring 2 – 20" Jumpers" or "Novice B – Sunday." Specific names help participants quickly identify their run without needing to scroll through the full list.
</Tip>

## Edit or Reorder Runs

After a run is created, you can edit its name and style, or change the order in which runs appear in your event. To reorder runs, open your event's run list and use the drag handles to arrange runs in the sequence you want participants to see. To edit a run's details, tap the run and select the edit option.

## Switching Between Host View and Participant View

As you build out your runs and populate them with dogs, it's helpful to preview exactly what your participants see. Use the **Switch View** feature in the app to toggle between your Host dashboard — where you manage statuses, check in dogs, and send messages — and the Participant View, which shows the live run order, dog statuses, and scoreboard exactly as attendees experience them.

<Note>
  Switching to Participant View is read-only — you won't be able to make edits until you switch back to Host View.
</Note>
