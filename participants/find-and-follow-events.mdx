Queme makes it easy to find any dog event near you and stay in the loop from the moment you arrive until the last run is complete. Once you follow an event, you receive push notifications from the host, gain access to the live run order, and can track individual dogs as they move through the lineup — all without refreshing or asking around ringside.

## Search for an Event

<Steps>
  <Step title="Open the Queme App">
    Launch Queme on your iOS or Android device. Sign in with your Google, Apple, email, or Facebook account if prompted.
  </Step>
  <Step title="Browse or Search for Events">
    From the home screen, use the search bar to look up an event by name, or scroll through the list of upcoming events displayed on the main feed. Events are listed with their name, date, and location so you can quickly identify the one you're looking for.
  </Step>
  <Step title="Tap the Event">
    Tap the event card to open the full event detail view. Here you'll see the event schedule, the list of runs (organized like a whiteboard or time-slot lineup), and any updates the host has already posted.
  </Step>
  <Step title="Tap Follow">
    Tap the **Follow** button on the event page. Following the event subscribes you to all event-level push notifications and gives you ongoing access to the live run order and schedule as the host updates them throughout the day.
  </Step>
</Steps>

## What You See After Following

Once you follow an event, your event view populates with everything you need to stay oriented on show day:

<CardGroup cols={2}>
  <Card title="Run List" icon="list-ol" href="/participants/tracking-your-dog">
    See every run (time slot or class) the host has created, organized in the order they'll take place. Each run shows its name and, once the host opens check-in, the dogs entered in it.
  </Card>
  <Card title="Dog Entries" icon="paw" href="/participants/tracking-your-dog">
    Tap into any individual run to see the full list of dogs entered. From here you can tap the bell icon next to any dog to subscribe to their specific status notifications.
  </Card>
  <Card title="Event Schedule" icon="calendar-days" href="/participants/notifications">
    View the host's published schedule so you know when each run is expected to begin. Hosts can update this in real time if timing shifts during the day.
  </Card>
  <Card title="Host Updates" icon="bell" href="/participants/notifications">
    Receive push notifications whenever the host broadcasts an announcement, posts a delay, or sends any event-wide message to followers.
  </Card>
</CardGroup>

## Runs and Dog Lists

Every event is divided into one or more **runs** — think of these as the individual classes, rings, or time slots that make up the event. Each run contains the list of dogs entered in that session. Tap any run to expand it and see the dogs, their current status (Checked In, In Line, Running, or Completed), and, if the host has enabled scoring, their scores as they come in.

<Note>
  You can follow as many events as you like at the same time. If you no longer want updates from a particular event, simply open it and tap **Unfollow** — you'll stop receiving notifications and the event will be removed from your active feed.
</Note>
