Queme gives you a live, real-time view of exactly where your dog stands in the run order — no more standing ringside wondering how many dogs are ahead of you. Each run inside an event contains a full list of entered dogs, and every dog moves through a defined set of statuses as the host manages the day. You can subscribe to notifications for any individual dog so you're alerted the moment their status changes.

## Opening a Run and Finding Your Dog

After you follow an event (see [Find and Follow Events](/participants/find-and-follow-events)), tap on any run from the event view to see its full dog list. Dogs are displayed with their name and current status. Scroll through the list to find your dog, or any dog you want to keep an eye on.

## The Bell Icon — Per-Dog Subscriptions

Each dog entry in a run has a **bell icon** next to it. Tapping the bell subscribes you to push notifications specifically for that dog. You'll receive an alert every time the host updates that dog's status — for example, when your dog moves from **In Line** to **Running** — so you know it's time to head to the ring.

<Tip>
  You can tap the bell icon on any dog in the run — not just your own. This is useful if you're helping a friend, running multiple dogs under different handlers, or just keeping track of a competitor's progress.
</Tip>

## Dog Status Flow

Hosts move dogs through four statuses over the course of the event. These statuses update in real time and are visible to anyone viewing the run:

<Steps>
  <Step title="Checked In">
    The dog has arrived at the event and been checked in by the host or a gate steward. The dog is confirmed as present and accounted for in the run.
  </Step>
  <Step title="In Line">
    The dog is actively queued and coming up soon. If you have the bell icon enabled for this dog, you'll receive a push notification as soon as this status is set — giving you time to get to the ring.
  </Step>
  <Step title="Running">
    The dog is currently on course or in the ring. Their run is in progress right now.
  </Step>
  <Step title="Completed">
    The dog has finished their run. The host moves the dog to the **Completed** tab once they're done, keeping the active list clean and easy to read. If scoring is enabled, the dog's score may also appear at this stage.
  </Step>
</Steps>

## Scores

If the host has enabled scoring for the event, scores appear alongside dog entries as they are recorded. Scores update live as the host enters them — you don't need to refresh the page. Check the [Live Scoreboard](/participants/live-scoreboard) page for more detail on how the scoring view works.

<Note>
  Push notifications for dog status changes only reach you if notifications are enabled for Queme on your device. If you're not receiving alerts, check your device's notification settings and make sure you've tapped the bell icon on the dog you want to follow. See [Notifications](/participants/notifications) for full troubleshooting steps.
</Note>
